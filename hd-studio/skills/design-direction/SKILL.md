# Design direction

Read the HD guide, standards and current brief. Define the visual concept, typography and license status, palette with accessible foreground/background pairs, spacing, imagery plan, responsive behavior, page hierarchy, CTA and content tone. Offer one recommended direction and explain how it fits the audience. Reuse section logic where appropriate; avoid generic visual sameness. Use real approved imagery or labeled placeholders.

Output docs/hd/design.md, with a section-by-section specification and acceptance checks for mobile, keyboard and contrast. List unresolved approvals. Handoff to build-preview.
